Trang chủ

Code++ là một code editor nhẹ dành cho Windows, được thiết kế để cung cấp môi trường đơn giản và dễ sử dụng cho việc viết và thử nghiệm mã nguồn.

Project hiện đang được phát triển và hỗ trợ nhiều ngôn ngữ lập trình khác nhau.

Code++ là gì?

Code++ là một dự án code editor tập trung vào sự đơn giản, nhẹ và dễ sử dụng trên Windows.

Project được phát triển với mục tiêu cung cấp một công cụ nhỏ gọn để viết, chỉnh sửa và chạy code mà không cần một IDE quá nặng.

Tính năng

  • Giao diện code editor đơn giản.
  • Hỗ trợ nhiều ngôn ngữ lập trình.
  • Chỉnh sửa source code.
  • Chạy và kiểm tra chương trình.
  • Hỗ trợ C và C++.
  • Hỗ trợ Python.
  • Hỗ trợ Java Edition.
  • Hoạt động trên Windows.

Code++ hướng tới việc hỗ trợ nhiều ngôn ngữ lập trình và ngôn ngữ đánh dấu.

Bắt đầu

Tải phiên bản Code++ phù hợp, giải nén nếu sử dụng bản ZIP, sau đó chạy ứng dụng.

Chạy chương trình

Viết hoặc mở source code trong Code++, chọn ngôn ngữ tương ứng và sử dụng chức năng chạy chương trình nếu môi trường cần thiết đã được cài đặt trên Windows.

Xử lý lỗi

Nếu chương trình không chạy, hãy kiểm tra compiler, runtime hoặc các công cụ cần thiết cho ngôn ngữ đang sử dụng.
