# Code++

Code++ is a lightweight code editor for Windows.

## Editions

### C++ Edition

Current version: **1.1.3**

Supports:

* C
* C++
* Python
* Text editing

Download the latest version:

**CodePlusPlus-1.1.3.zip**

Previous version:

**CodePlusPlus-1.1.2.zip**

### Java Edition

Current version: **1.2.0**

The Java Edition is distributed as a Windows installer.

**Code++ Java Edition 1.2.0**
